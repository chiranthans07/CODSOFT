# Advanced Calculator - Python

## Description
This is a command-line calculator built using Python. 
It allows users to perform basic arithmetic operations 
such as addition, subtraction, multiplication, and division.

## Features
- Uses functions for better structure
- Supports continuous calculations using a loop
- Handles division by zero
- Handles invalid numeric input using try-except
- User-friendly interface

## How to Run
1. Open terminal
2. Navigate to project folder
3. Run: python calculator_v2.py

## Technologies Used
- Python 3
